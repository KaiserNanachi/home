# 適応学習

統計検定準1級と中国語の入口に、同じ復習エンジンを使った学習画面を表示します。統計の章・ラボ・演習室と、中国語の単語一覧・単語テスト・音声練習も利用できます。

## 出題と評価

- 学習時間、目標、範囲、予定日を設定できます。復習期限、誤答、前提知識、項目の重要度を使い、残り時間の目安に合わせて次の問題を選びます。出題中に選択理由を確認できます。
- 新規項目では事前問題から始めます。訂正や模範解答は回答後に表示します。「思い出せない」は検索の失敗として記録し、空欄のまま中断した場合は下書きのみを保存します。
- 検索練習と分散学習を組み合わせます。自力正答までに使ったヒント、前回の失敗、前回からの経過などに基づき、復習予定を更新します。語彙の想起確率はモデルによる推定値です。日数や係数は実装上の初期値であり、対象教材で妥当性を実測した値ではありません。
- 認識、自力再現、原理の説明、類似概念の識別、定型への適用、初見への応用、時間をおいた再現を分けます。回答実績がない能力は未測定と表示し、自己評価の件数も表示します。長期定着の判定には、異なるセッションでの遅延再現が複数回必要です。そのうち一回は前回の再現から7日以上経過したものです。

設計の参考文献は [検索練習と分散学習](https://doi.org/10.1038/s44159-022-00089-1)、[自己説明](https://doi.org/10.1007/s10648-018-9434-x)、[交互学習](https://doi.org/10.1037/bul0000209) です。

## データと公開

- `adaptive-engine.js` が履歴から復習予定と習熟状態を再計算します。`adaptive-ui.js` は学習画面、設定、知識マップ、分析を提供します。各教材アダプターでテーマ、項目、前提関係、問題、評価基準を定義します。項目と問題のIDは既存の回答に結び付くため、教材を更新するときも維持してください。
- `adaptive-study:v1:<科目>:` を接頭辞に使い、回答イベント、設定、セッション、下書きをブラウザーに保存します。統計の既存の保存形式は維持し、日時のある最終回答を一回分の証拠として取り込みます。旧教材の記録初期化は従来の記録だけが対象です。
- 公開先は `docs/learning/` です。HTML、各教材アダプター、共通エンジン、UI、CSSを公開先にも同期してください。学習履歴は同じブラウザーの同じオリジンで利用でき、設定画面からJSONで書き出し・取り込みができます。

## 検証

Node.js と jsdom が利用できる環境で、リポジトリのルートから実行します。統合テストは既定で `docs/learning/` を読み込みます。`STUDY_SOURCE=1` で `learning/` を確認できます。

```sh
node --test tests/adaptive-engine.test.cjs tests/adaptive-pages.test.cjs
```
