# 適応学習

統計検定準1級と中国語の入口に、同じ復習エンジンを使った学習画面を表示します。統計の章・ラボ・演習室と、中国語の単語一覧・単語テスト・音声練習も利用できます。

## 出題と評価

- 学習時間、目標、範囲、予定日を設定できます。復習期限、誤答、前提知識、類似して混同しやすい概念（交互学習対象）、項目の重要度を使い、残り時間の目安に合わせて次の問題を選びます。出題中に選択理由を確認できます。
- セッション開始時に、復習期限数・新規項目数・目標に応じて 5 フェーズ（既習の検索練習／新規知識の獲得／自己説明・構造化／応用・交互学習／誤答分析・再確認）の時間配分を動的に構成します。
- 新規項目では事前問題から始めます。訂正や模範解答は回答後に表示し、習熟度に応じた段階的支援縮小（Fading）として、初学者・要再学習項目では解答例を展開表示、習得済み項目では折りたたみます。「思い出せない」は検索の失敗として記録し、空欄のまま中断した場合は下書きのみを保存します。
- 検索練習と分散学習を組み合わせます。語彙・記憶項目には FSRS 型のべき乗忘却曲線 $R(t, S) = (1 + \frac{3}{17}\frac{t}{S})^{-1}$（$R(S, S)=0.85$）と、想起確率・難易度・暗黙の4段階評価（Again / Hard / Good / Easy）に基づく安定性更新を用います。高次の概念理解や技能項目（`kind: 'skill'`）は間隔反復のみに依存せず、自己説明・識別・応用・転移の結果と併用します。語彙の想起確率はモデルによる推定値であり、実測値とは画面上で視覚的に区別しています。
- 誤答時には9種類の誤答原因を選択でき、原因に応じた改善アドバイスを表示します。高い確信度での誤答は誤概念候補として記録し（ハイパーコレクション効果を踏まえた優先処理）、次回以降の出題で優先します。
- 認識、自力再現、原理の説明、類似概念の識別、定型への適用、初見への応用、時間をおいた再現の7軸を分けます。回答実績がない能力は未測定と表示し、自己評価の件数も表示します。長期定着の判定には、異なるセッションでの遅延再現が複数回必要です。そのうち一回は前回の再現から7日以上経過したものです。
- 知識マップでは、前提知識の依存関係をインタラクティブな SVG グラフで可視化し、未学習・学習済み・再学習が必要・習得済み・長期定着済みの状態を確認できます。

## データと公開

- `adaptive-engine.js` が履歴から復習予定・FSRS状態・誤概念・セッション配分・メタ認知キャリブレーションを再計算します。`adaptive-ui.js` は学習画面、設定、知識マップ（SVG 依存グラフ付き）、分析を提供します。各教材アダプターでテーマ、項目、前提関係、混同しやすい概念（`confusables`）、問題（自己説明の観点 `lens` を含む）、評価基準を定義します。項目と問題のIDは既存の回答に結び付くため、教材を更新するときも維持してください。
- `adaptive-study:v1:<科目>:` を接頭辞に使い、回答イベント、設定、セッション、下書きをブラウザーに保存します。統計の既存の保存形式は維持し、日時のある最終回答を一回分の証拠として取り込みます。旧教材の記録初期化は従来の記録だけが対象です。
- 公開先は `docs/learning/` です。HTML、各教材アダプター、共通エンジン、UI、CSSを公開先にも同期してください。学習履歴は同じブラウザーの同じオリジンで利用でき、設定画面からJSONで書き出し・取り込みができます。

## 検証

Node.js（18以上）と jsdom が利用できる環境で、リポジトリのルートから実行します。統合テストは既定で `docs/learning/` を読み込みます。`STUDY_SOURCE=1` で `learning/` を確認できます。

```sh
node --test tests/adaptive-engine.test.cjs tests/adaptive-pages.test.cjs
```
